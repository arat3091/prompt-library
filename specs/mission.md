# Mission

## Core Purpose
Create an application for managing prompts with the ability to save, read, and edit prompts efficiently.

## Target Users
- **Readers**: Anyone can read and view existing prompts
- **Writers/Editors**: Only the author (you) can create, save, and edit prompts

## Key Value Proposition
A centralized, accessible platform to:
- Store prompts for reuse and reference
- Quickly retrieve saved prompts
- Modify and improve prompts over time
- Enable read-only access for others to benefit from curated prompts

## Core Features
1. **Save**: Persist new prompts to storage
2. **Read**: Retrieve and display prompts (public access)
3. **Edit**: Modify existing prompts (author-only access)
